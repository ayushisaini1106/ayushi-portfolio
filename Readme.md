# Ayushi Saini - Full Stack Developer Portfolio

Professional portfolio website for Ayushi Saini, a Full Stack Developer focused on React.js, Next.js, Node.js, Express.js, REST APIs, MongoDB, PostgreSQL, and Prisma ORM.

## Live Site

[https://ayushi-saini.vercel.app/](https://ayushi-saini.vercel.app/)

## Overview

This portfolio is a static site built with HTML, Tailwind CSS via CDN, Remix Icons, custom CSS, and GSAP animations. It uses a dark-first responsive design, smooth navigation, recruiter-friendly content sections, featured projects, direct contact actions, and a downloadable resume.

## Sections

- Hero with Full Stack Developer positioning
- About and recruiter snapshot
- Professional experience timeline (Xzect Labs Private Limited)
- Categorized technical skills (React.js, Next.js, Node.js, MongoDB, PostgreSQL, Prisma ORM, Antigravity, Claude)
- Featured projects (AI Trip Planner, Art & Crafts, News SocialXN, JSON Schema Builder)
- Education (B.Tech CSE - S.D. College of Engineering and Technology) & Certifications (MERN Training - QSpiders)
- Direct contact actions (Email, Phone, LinkedIn, GitHub, Resume)
- Dynamic footer year

## Project Coverage

The projects section highlights **AI Trip Planner** (Python, Groq API, Streamlit, LLMOps), **Art & Crafts** (Next.js, PostgreSQL, Prisma ORM, Zustand), **News SocialXN** (Next.js, React.js), and **JSON Schema Builder** (React.js, JSON UI) with source links and live links.
